# Cameras App

Camera management and integration.

## Overview
This Django app manages traffic cameras, their configurations, live feeds, and integration with AI services for vehicle detection and tracking.

## Planned Features
- Camera registration and management
- Live feed integration
- Camera configuration management
- AI service integration
- Camera health monitoring
